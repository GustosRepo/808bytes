# Launch Checklist

## Brand and Content
- Confirm logo and brand assets
- Finalize category names and descriptions
- Verify product copy for all listings
- Ensure all product images are optimized

## Product and Pricing
- Validate all paid prices
- Confirm free products are marked correctly
- Test links for checkout and downloads
- Confirm merch stock statuses

## UX and QA
- Test lane carousels on desktop, tablet, mobile
- Verify keyboard navigation and focus states
- Check search and filter behavior
- Validate cart calculations and totals

## Technical
- Configure analytics and key events
- Add metadata and Open Graph tags
- Generate sitemap and robots rules
- Set up 404 and fallback pages

## Legal and Policies
- Publish Privacy Policy
- Publish Terms of Service
- Publish Refund Policy
- Add contact/support details

## Pre-Launch Testing
- Run test orders with multiple product combinations
- Run free download claim tests
- Validate success/failure states
- Verify confirmation emails if enabled

## Launch Day
- Deploy production build
- Smoke test main user flows
- Monitor checkout and error logs
- Announce launch on social channels
