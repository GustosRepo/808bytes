# Site Architecture

## Page Map
1. Home
2. Category (optional in MVP)
3. Product Detail
4. Cart
5. Checkout
6. Success/Download Confirmation
7. Legal Pages (Privacy, Terms, Refunds)

## Home Structure
- Top Bar
- Hero Strip
- Track Lanes Section
- Footer

## Top Bar
- Logo
- Search input
- Filter toggles (Free/Paid)
- Cart icon and count

## Track Lane Pattern
Each lane represents one category.

Lane regions:
- Left rail: lane label, color marker, quick actions
- Main rail: horizontal carousel of product cards

## Product Card Pattern
- Cover image
- Product name
- Type label (VST, Pack, One Shot, Merch)
- Price badge (or Free)
- CTA button

## Product Detail Surface
- Gallery image
- Description
- Included files/content
- Compatibility notes
- CTA (Buy now / Download free)

## Navigation Rules
- Keep user on Home when browsing lanes
- Open detail in panel first for quick shopping
- Allow full detail page for SEO and sharing

## Responsive Behavior
- Desktop: multiple cards visible per lane
- Tablet: reduced card count per viewport
- Mobile: single-card dominant snapping carousel
